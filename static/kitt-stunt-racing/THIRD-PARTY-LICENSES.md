# Bibliothèques incluses avec KITT Stunt Racing

Les moteurs 3D et physiques sont embarqués localement pour que le jeu ne dépende pas d’un CDN tiers :

- **Three.js 0.128.0** — licence MIT, copyright © 2010–2021 Three.js authors. Texte complet : `lib/THREE-LICENSE.txt`.
- **Cannon.js 0.6.2** — licence MIT, copyright © 2012 cannon.js authors. Texte complet : `lib/CANNON-LICENSE.txt`.

`js/audio.js`, `js/scores.js` et `js/editor.js` sont les modules locaux du jeu. Les sons sont générés dans le navigateur ; les scores et circuits restent dans le stockage local de l’appareil.
