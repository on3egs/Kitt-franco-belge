Comment démarrer ?

  1. Ouvrez « Cockpit » en bas à droite.
  2. Dans « Cette page », ajoutez un favori ou marquez votre position.
  3. Dans « Carnet », gardez votre première idée.
  4. Dans « Ambiance », choisissez vos couleurs, votre volume et vos animations.

Les réglages de ce cockpit n’envoient pas vos notes sur un serveur. Les applications gardent leurs commandes et leurs réglages propres. Sur une interface sans titres de lecture, le sommaire n’est pas affiché.

Le minuteur s’arrête si vous fermez ou rechargez la page. Pensez à exporter les notes importantes : effacer les données du navigateur efface aussi votre carnet.
