Field Vault aide à préparer, avant une coupure, une bibliothèque personnelle de ressources éducatives et publiques : histoire, sciences, eau, énergie, orientation, électronique et radio.

Télécharger pour Windows 64 bits ↓ Ouvrir l’application web ↗

Bêta portable Windows x64. L’application web s’installe depuis un navigateur compatible.

01 / PRÉPARER

Choisir les sources

Catalogue Kiwix, données cartographiques ouvertes, documents publics et ressources dont la licence permet l’archivage.

02 / CONSERVER

Garder une copie locale

Le compagnon de bureau collecte un nombre limité de pages publiques, respecte robots.txt et indexe le texte sur l’appareil.

03 / RETROUVER

Consulter sans réseau

Recherche locale dans les pages capturées, notes radio stockées sur l’appareil et position GPS seulement si vous l’autorisez.

Version bêta — Windows x64 disponible.

Le compagnon Windows est un exécutable portable, sans installateur système pour l’instant. L’application web peut être installée depuis un navigateur moderne. Les paquets Linux, Android, iOS et macOS demandent des constructions et vérifications propres à chaque système ; ils ne sont pas encore disponibles.
