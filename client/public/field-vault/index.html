Le savoir reste
avec vous.

Field Vault conserve localement une petite sélection de pages publiques autorisées. La collecte exige Internet; les pages déjà enregistrées se recherchent ensuite sur cet appareil.

Installer Windows 10/11 x64 ↓ Linux ARM64 (.deb) Linux x86_64 (.deb) Mode d’emploi Ouvrir l’application web ↗

Windows 10/11 x64: installateur autonome. Linux ARM64 et x86_64: paquets .deb. XP/7 non pris en charge.

01 / PRÉPARER

Choisir les sources

Catalogue Kiwix, données cartographiques ouvertes, documents publics et ressources dont la licence permet l’archivage.

02 / CONSERVER

Garder une copie locale

Le compagnon de bureau collecte un nombre limité de pages publiques, respecte robots.txt et indexe le texte sur l’appareil.

03 / RETROUVER

Consulter sans réseau

Recherche locale dans les pages capturées, notes radio stockées sur l’appareil et position GPS seulement si vous l’autorisez.

Version bêta 0.1: Windows x64, Linux ARM64 et Linux x86_64.

Windows 10/11 x64: le runtime Python et les fichiers de l’application sont inclus dans l’installateur; un navigateur installé reste nécessaire. Linux: paquets .deb construits sur leurs architectures respectives; libc et le navigateur restent fournis par Linux. XP/7, macOS, Android et iOS ne sont pas pris en charge par ces installateurs.
