LA BOÎTE À OUTILS

Une action claire.
Un fichier prêt à repartir.

Choisissez l’opération, réglez les options utiles et exportez un nouveau fichier. Les limites et formats sont indiqués dans l’application.

01 / IMAGE

Redimensionner & convertir

Ajustez les dimensions, gardez les proportions et exportez en WebP, JPEG ou PNG.

IMAGE → WEBP · JPG · PNG
02 / AUDIO

Découper un passage

Saisissez le début et la fin en secondes pour créer un extrait WAV PCM local.

AUDIO → WAV PCM
03 / VIDÉO

Créer une planche de scènes

Extrayez 6, 9 ou 12 vignettes horodatées pour parcourir rapidement une vidéo.

VIDÉO → PLANCHE JPEG
04 / PDF

Fusionner des documents

Assemblez jusqu’à 20 fichiers PDF dans l’ordre sélectionné. Les originaux restent intacts.

PDF + PDF → PDF
05 / TEXTE

Passer de TXT à RTF

Créez un document Word éditable à partir d’un fichier texte ou Markdown simple.

TXT · MD → RTF
+ CONTRÔLE

Aperçu et choix

Vérifiez le fichier, la taille et les réglages avant de lancer chaque export.

VOUS GARDEZ LA MAIN
MODE LOCAL

Vos fichiers restent chez vous.

KITT Media Lab ouvre les fichiers que vous choisissez et effectue les opérations dans Microsoft Edge sur votre ordinateur. L’application n’a pas de fonction d’envoi, de compte ni de serveur de conversion. Évitez toutefois de traiter un fichier si Windows ou votre antivirus vous indique qu’il est dangereux.

QUESTIONS FRÉQUENTES

À savoir avant l’installation.

Le logiciel est-il gratuit ?

Oui, l’application est proposée gratuitement par KITT Franco-Belge / By Manix.

Quels formats sont réellement créés ?

WebP/JPEG/PNG pour les images, WAV PCM pour l’audio, JPEG pour les planches vidéo, PDF pour les fusions et RTF pour les fichiers texte.

Pourquoi certains fichiers ne s’ouvrent pas ?

Les codecs disponibles dans Microsoft Edge varient. Une vidéo ou un audio peut être refusé si son codec n’est pas pris en charge, même si l’extension paraît correcte.

L’installation est-elle signée ?

Non. Cette version communautaire n’a pas de signature de code; Windows SmartScreen peut donc demander une confirmation. Vérifiez que le nom du fichier correspond à celui indiqué sur cette page.

Le code source est-il libre ?

L application est téléchargeable et utilisable gratuitement, mais le code KITT reste couvert par les conditions publiées. Les bibliothèques tierces ont leurs licences propres.
