AVANT DE TÉLÉCHARGER

Ce qu’il faut savoir.

Configuration requise

  • Windows 11 64 bits
  • Microsoft Edge, inclus avec Windows 11
  • Windows PowerShell 5.1 et Windows Forms, inclus dans Windows
  • La taille exacte et le SHA-256 sont affichés avec le téléchargement

Fonctionnement local

  • Pas d’AGX, de Jetson ou de serveur
  • Pas de compte ou de clé d’accès
  • Pas de connexion Internet pour jouer après l’installation
  • Scores et réglages restent sur le PC

Voix et sécurité

  • Les annonces du bouton utilisent la voix française disponible dans Edge
  • Le cockpit n’envoie pas tes données à un backend
  • L’installateur n’est pas signé numériquement; Windows peut afficher un avertissement SmartScreen

La version Windows regroupe les fichiers locaux du cockpit web. Elle n’installe pas le modèle IA du chatbot KYRONEXT et ne se connecte pas automatiquement à l’AGX.
