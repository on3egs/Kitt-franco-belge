# Manix Arcade Classics

Ten original browser games, made from canvas, JavaScript and CSS in this project. The rules draw inspiration from familiar arcade genres; the code, presentation and visuals here are original and use no copied game sprites or music.

## The ten games

1. Neon Serpent — grid survival
2. Breaker X — paddle and bricks
3. Pong Arena — ten tactical duels
4. Crossroad 86 — timing and traffic
5. Asteroid Shift — inertia-based space survival
6. Memory Core — Simon-style sequence memory
7. Minefield — logic puzzle
8. KITT 2048 — tile merging
9. Invaders Zero — wave shooter
10. Missile Command — point-defense strategy

Each game has a ten-level campaign, keyboard and touch support where the game permits it, pause/restart controls, sound toggle, and a record saved in the browser. Records from this collection and compatible KYRONEXT games appear in `/static/games/high-scores.html`.

The Hall of Fame is local to the current browser profile. It does not publish player names or scores to a server.
