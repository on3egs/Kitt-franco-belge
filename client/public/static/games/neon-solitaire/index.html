NEON SOLITAIRE

Range les 52 cartes dans les quatre familles. Clique une carte visible, puis clique sa destination. Les règles essentielles sont juste ici.

COMMENT JOUER · 3 RÈGLES SIMPLES
01
Construis les colonnes

Pose une carte sur une carte de couleur opposée et de valeur immédiatement supérieure. Exemple : rouge 8 sur noir 9. Une colonne vide ne reçoit qu’un Roi.

02
Révèle les cartes

La dernière carte cachée se retourne quand tu libères sa place. Une carte visible entraîne avec elle toute la suite située dessous.

03
Complète les familles

Commence chaque fondation par un As, puis monte jusqu’au Roi avec la même famille : pique, cœur, carreau ou trèfle.

Pour jouer : clique une carte, puis sa colonne ou sa fondation. Clique la pioche pour retourner une carte ; quand elle est vide, clique-la pour recycler. Échap désélectionne · H indice · Ctrl+Z annuler.
