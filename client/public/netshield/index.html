Installer en trois étapes

  1. Ouvrez Manix-NetShield-PC-1.0.0-Setup.exe et validez la demande administrateur Windows.
  2. Terminez l’installation illustrée KITT. Le moteur et l’interface sont installés ensemble.
  3. Cliquez sur Protéger ce PC, vérifiez « DNS local » sur votre carte et rechargez vos pages.

Aucun Python ou matériel externe. Le logiciel utilise .NET Framework 4.8, PowerShell et les voix déjà présents dans Windows 11.

Vous gardez le contrôle

Pause/reprise, liste actualisée chaque jour, règles d’autorisation et de blocage, compteurs et diagnostic exportable.

Les DNS d’origine sont sauvegardés. Restaurer mes DNS les rétablit ; l’adresse IP, la passerelle et le Wi-Fi ne sont pas modifiés.

L’installation seule n’active pas les DNS sur vos cartes : le bouton « Protéger ce PC » réalise cette étape.

Ce que le filtre peut faire

Il bloque les domaines publicitaires et de suivi de sa liste. Les annonces du même domaine que le contenu peuvent rester visibles. Un navigateur avec DNS sécurisé personnalisé ou un VPN peut contourner le filtrage.

Après pause/reprise, rechargez les pages. Les caches et connexions propres au navigateur peuvent persister.

Installation du compagnon AGX

  1. Téléchargez et décompressez le paquet Windows.
  2. Double-cliquez sur Installer-Manix-Windows.bat.
  3. Suivez la fenêtre illustrée KITT. L’icône animée apparaît dans la zone de notification et démarrera avec votre session.
  4. Pour faire passer l’accès Internet du PC par l’AGX, lancez ensuite « Configurer Internet Manix » depuis le menu Démarrer.

Le PC n’a rien d’autre à installer

Windows 11 fournit PowerShell, .NET Windows Forms et System.Speech, utilisés par l’installateur et l’icône animée/vocale. Aucun Python ni pilote tiers n’est nécessaire sur le PC.

Le filtre DNS tourne sur l’AGX. Ses dépendances Python, dnsmasq, systemd et outils réseau sont installés par install_orin.sh depuis le paquet complet.

Raccordement réseau

La box reste sur le port WAN de l’AGX, adresse 192.168.129.24. Le PC se branche au port LAN 192.168.50.1. Le guide explique la configuration, le tableau de bord et les limites du filtrage DNS.

Ouvrez le guide complet sur l’AGX après le raccordement.
