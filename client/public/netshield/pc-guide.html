Aucun Jetson ni Raspberry Pi nécessaire. Le moteur tourne sur votre ordinateur.

1. Installation et premier démarrage

  1. Sur Windows 11 x64, ouvrez Manix-NetShield-PC-1.0.0-Setup.exe et validez la demande administrateur Windows.
  2. Choisissez les raccourcis, puis terminez l’installation. Le service DNS démarre ; vos cartes réseau ne sont pas encore modifiées.
  3. Dans le tableau de bord, cliquez sur Protéger ce PC. Cette étape sauvegarde les DNS actuels de chaque carte physique connectée et les remplace par 127.0.0.1 et ::1.
  4. Vérifiez que votre carte affiche DNS local. Rechargez vos pages. Les compteurs augmentent lorsque le moteur reçoit des requêtes.

Le paquet comprend le moteur, la liste initiale de domaines, les visuels, les scripts, l’icône animée et ce guide. Il utilise .NET Framework 4.8, PowerShell et les voix de Windows 11. Aucun Python ou téléchargement de runtime tiers n’est requis.

L’exécutable n’est pas signé avec un certificat commercial. Windows peut afficher un avertissement de réputation. Vérifiez la provenance et l’empreinte SHA-256 publiée avant de décider de l’exécuter ; ne désactivez pas la protection de Windows.

3. Suspendre, reprendre, tester

Suspendre le filtre laisse passer les domaines. Réactiver le filtre applique à nouveau la liste et vos règles. Les réponses bloquées et celles transmises pendant la pause portent un TTL nul ; le cache DNS Windows est vidé au changement.

Un navigateur peut conserver sa propre résolution et des connexions déjà ouvertes. Fermez les onglets concernés, rechargez ou redémarrez le navigateur pour comparer. La présence d’un encart publicitaire vide n’indique pas forcément un échec.

Dans PowerShell, Resolve-DnsName doubleclick.net -Type A -Server 127.0.0.1 doit renvoyer 0.0.0.0 lorsque ce domaine est bloqué. Cette commande teste le moteur directement, pas le passage effectif de votre navigateur par celui-ci. Comparez les compteurs pendant une navigation.

Les DNS sécurisés personnalisés (DoH) d’un navigateur, VPN ou outil réseau peuvent contourner ce filtre. Dans les paramètres du navigateur, utilisez les DNS du système si vous souhaitez passer par Manix. Le logiciel ne modifie pas ces réglages à votre insu.

4. Vos règles, la voix et l’icône KITT

Dans Mes règles, entrez un domaine sans protocole ni chemin. Autoriser et Bloquer s’appliquent aussi aux sous-domaines. Retirer ma règle rétablit le comportement de la liste principale. Si le site utilise un alias DNS vers un autre domaine bloqué, ce domaine peut également nécessiter une exception.

L’onglet Guide & voix active les annonces avec une voix installée dans Windows. Elles sont désactivées par défaut. L’icône animée dans la zone de notification ouvre le tableau de bord par double-clic. Un clic droit donne accès aux principales commandes. Fermer la fenêtre la réduit dans cette zone ; quitter l’interface ne coupe pas le service de filtrage.

5. Restauration et panne

Restaurer mes DNS remet les serveurs DNS statiques sauvegardés ou le mode automatique d’origine. Ni l’adresse IP, ni la passerelle, ni le mot de passe Wi-Fi ne sont modifiés. L’arrêt explicite du service restaure aussi les DNS ; un arrêt normal de Windows conserve la configuration pour le démarrage suivant.

Windows tente de relancer le service en cas de panne. Une tâche de secours contrôle chaque minute la réponse du DNS local et tente de restaurer les DNS sauvegardés si le moteur ne répond plus. Une interruption temporaire est donc possible ; une politique système ou une carte absente peut empêcher la restauration.

La désinstallation passe d’abord par la restauration. Si une carte sauvegardée est absente, rebranchez-la puis réessayez. La sauvegarde reste dans C:\ProgramData\Manix\NetShieldPC\dns-backup.json jusqu’à restauration complète. Ne l’effacez pas pour forcer une désinstallation.

Si le moteur ne démarre pas, vérifiez qu’aucun autre serveur DNS n’occupe le port local 53. Les cartes virtuelles, VPN et configurations d’entreprise ne sont pas configurés automatiquement. L’édition AGX reste un produit séparé.

6. Données, mises à jour et limites

La liste initiale provient de StevenBlack/hosts (publicité, suivi et domaines malveillants). Elle est mise à jour cinq minutes après le démarrage puis toutes les 24 heures, ou sur demande. Un téléchargement invalide conserve la liste précédente. La mise à jour du logiciel lui-même se fait avec un nouvel installateur.

Les requêtes autorisées vont à Cloudflare 1.1.1.1, avec Quad9 9.9.9.9 en secours, par DNS classique. Les fournisseurs amont peuvent donc traiter ces requêtes. Manix n’installe pas de certificat, ne déchiffre pas le HTTPS et n’envoie aucune télémétrie à un serveur Manix.

Les compteurs et les 12 derniers domaines bloqués sont en mémoire, accessibles aux sessions locales de ce PC et effacés au redémarrage du moteur. Les règles, DNS sauvegardés et erreurs techniques restent localement. Un diagnostic exporté contient les noms de cartes et les derniers domaines bloqués : examinez-le avant partage.

Un filtre DNS ne supprime pas toutes les publicités. Les annonces servies par le même domaine que le contenu, notamment certaines vidéos, peuvent rester visibles. Il ne remplace pas un antivirus. Le filtrage n’est pas une garantie de sécurité ou de confidentialité.

7. Vérifications de cette première version

Le moteur a été testé sur Windows, en environnement isolé : UDP/TCP, IPv4/IPv6, alias DNS, règles, cinq cycles pause/reprise, paquets malformés et persistance. La sauvegarde et la restauration DNS ont été testées avec des cartes simulées, y compris panne partielle et carte absente.

L’installateur a été compilé. L’installation complète avec élévation administrateur et l’activation sur une vraie carte restent à valider sur un PC de test. Cette première édition est fournie avec cette limite clairement indiquée ; les essais de développement n’ont pas changé les DNS du PC de travail.
