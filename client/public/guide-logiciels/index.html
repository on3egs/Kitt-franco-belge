RÉPONSES SANS JARGON

Questions utiles

Pourquoi un lien fonctionne sur un site mais pas sur l’autre ?

Les deux sites sont hébergés et publiés séparément. Un fichier ajouté à KITT n’apparaît pas automatiquement sur KYRONEXT.EU. Le catalogue précise le lien où chaque version est réellement publiée.

Pourquoi le chatbot n’est-il pas « dans » le site ?

La page Web est l’écran de commande. Le Jetson fournit le modèle IA et les services. Si la machine est éteinte, si le tunnel est en panne ou si la connexion manque, l’interface peut s’ouvrir sans répondre.

Pourquoi les installateurs ne fonctionnent-ils pas sur tous les Windows ?

Un exécutable embarque un runtime et des fichiers qui ont une version minimale de Windows. Field Vault a été construit avec Python 3.13 : le paquet actuel ne prend pas en charge XP ni Windows 7. Il faut un build ancien distinct et des essais avant d’annoncer la compatibilité.

Comment vérifier si un téléchargement est un vrai installateur ?

La page doit présenter un nom de fichier, un système compatible et un bouton de téléchargement. Vérifiez aussi la taille ou l’empreinte publiée. « Ouvrir l’application Web » n’est pas un téléchargement.

Que faire si le téléchargement ou le service échoue ?

Vérifiez d’abord Internet, l’architecture et l’espace disque. Pour les outils qui dépendent d’un Jetson, vérifiez ensuite que celui-ci est allumé et connecté. Gardez le message d’erreur complet : il indique souvent si la panne vient du navigateur, du réseau ou du service.
