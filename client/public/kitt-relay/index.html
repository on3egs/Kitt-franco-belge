TRANSPARENCE

Ce qui se passe avec vos fichiers

Le contenu ne transite pas par le site. Après l’échange des codes, les deux navigateurs établissent un canal WebRTC direct. Le canal de données WebRTC utilise le chiffrement DTLS. Documentation WebRTC.

Aucun compte ni historique serveur. Les codes restent dans les champs; les blocs reçus peuvent rester temporairement dans la mémoire de l’onglet. Terminer la session efface ces données temporaires et les liens de téléchargement créés.

Limite de réseau. Le mode actuel utilise des candidats locaux sans serveur STUN/TURN. Les deux appareils doivent pouvoir communiquer directement sur le même réseau; certains routeurs ou réseaux isolent leurs appareils.

Échangez le code en privé. Il contient les paramètres et adresses candidates de cette connexion locale. Ne le publiez pas et ne le transmettez qu’à votre propre appareil destinataire.
